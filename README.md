# Friends Chatbot

A character chatbot trained on Friends TV show dialogue. Select a character (Ross, Rachel, Monica, Chandler, Joey) and chat in their style — powered by a fine-tuned language model with a Gradio web interface.

## Demo
![Friends Chatbot UI](demo/Screenshot%202025-11-30%20at%203.24.59%20AM.png)

## Features
- Per-character dialogue fine-tuning on Friends script corpus
- Gradio web UI with character portraits and themed background
- Supports Ross, Rachel, Monica, Chandler, and Joey
